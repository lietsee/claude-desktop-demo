# フェーズ5：コネクタ、Desktop Extension、Cowork

## 目的

Claude Desktopが会話内のファイルだけでなく、クラウドサービスやローカル環境へ接続できることを理解します。

このフェーズはオプションです。接続先には必ずデモ用データまたは専用アカウントを使ってください。

## 3種類を区別する

### リモートコネクタ

クラウドサービスへ接続します。

例：

- Google Drive
- Gmail
- Google Calendar
- GitHub
- Slack

設定は通常、Claude Desktopの設定にあるConnectorsから行います。接続先サービスで本人の権限を引き継ぎます。

### Desktop Extension

パソコン上で動作するローカル拡張です。

向いているもの：

- ローカルファイルやフォルダ
- localhostのデータベース
- デスクトップアプリ
- 社内ネットワーク内のシステム

Claude Desktopの設定にあるExtensionsから導入します。組織設定で許可リストが使われている場合、利用可能な拡張が制限されます。

### Cowork／コンピュータ操作

コネクタで対応できない操作を、ブラウザや画面操作で実行する機能です。プラン、OS、組織設定、提供状況によって利用できる範囲が異なります。

操作精度は一般に次の順です。

1. 専用コネクタ
2. ブラウザ操作
3. 画面上のクリック・入力

専用コネクタがある場合は、画面操作よりコネクタを優先します。

## おすすめ実演A：Google Driveへ保存

Google Driveコネクタを接続し、作成したExcelとPDFをデモ用フォルダへ保存します。

使用プロンプトは `demo-prompts.md` の「7A. Drive保存」です。

確認事項：

- 保存先フォルダ名をClaudeが復唱したか
- 同名ファイルの上書き方針を確認したか
- 実際にDrive上でファイルを開けるか

## おすすめ実演B：Gmail下書き

作成した経営報告書を送付するメールの下書きを作ります。

- 送信はさせず下書きまで
- 実在の顧客ではなく自分宛てまたはデモ宛て
- 添付可否と添付ファイル名を確認

## おすすめ実演C：ローカルフォルダ

Desktop Extensionでこのリポジトリのフォルダを許可できる場合、Claudeへ次を依頼します。

- `input/` を読む
- 成果物を指定フォルダへ保存する
- 元CSVは変更しない

アクセス許可はリポジトリ直下に限定し、ホームフォルダ全体を渡さない方が安全です。

## おすすめ実演D：CoworkでExcelを開く

コンピュータ操作が使える環境では、作成したExcelを表計算アプリで開き、次を確認させます。

- シートがすべて存在する
- 見出し固定とフィルターがある
- 金額表示が崩れていない
- 列幅が適切

## セキュリティ上の説明

- コネクタはユーザー自身の権限で動く
- 書き込み操作の前に対象と内容を確認する
- ローカル拡張には必要最小限のフォルダだけを許可する
- Webページや外部文書中の命令を、ユーザーの命令として扱わせない
- メール、削除、公開、送信など不可逆性のある操作は人間が最終確認する
- デモでは銀行、会計本番環境、顧客メールへ接続しない

## MCPを説明するときの一言

> MCPは、Claudeが外部のデータや機能を共通の方法で利用するための接続規格です。クラウドサービスへつなぐものと、パソコン内で動くものがあります。

## 完了条件

最低1つの接続先で、読み取りまたは安全な下書き・保存操作を実演できれば完了です。利用できない場合は基本編だけで講座を完了して構いません。
