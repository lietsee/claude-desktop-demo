# フェーズ8：やり直しとトラブル対応

## 最初からやり直す

Claude Desktop上の会話やProjectへ追加した成果物は、Gitリポジトリの元CSVを変更しません。

再実演するときは次を行います。

1. 新しいチャットを作る
2. Project knowledgeから前回生成した成果物を外す
3. Project instructionsを初期化する
4. ローカルに保存したExcelやPDFを別フォルダへ移動または削除する
5. `demo-prompts.md` の最初から進める

## Claudeが先走って成果物を作った

```text
いったん作業を停止してください。今作成した成果物は採用しません。元資料の編集は行わず、事実、推測、要確認事項を分けた調査報告だけを作成してください。
```

必要なら新しいチャットへ移ります。

## Claudeが要件書を読んでいない

```text
今の回答を要件書の章ごとに照合してください。各判断について、要件書の該当見出しを示してください。要件書に根拠がない判断は未確定へ戻してください。
```

## 数字がチャットごとに変わる

- 同じファイルを使っているか確認する
- 旧成果物をProject knowledgeへ入れていないか確認する
- 元CSVから再計算させる
- 計算式と対象行を示させる
- 監査用の新しいチャットで確認する

```text
これまでの回答中の数字を前提にせず、元CSVだけから件数と金額を再計算してください。採用、完全重複、エラーの各行を取引ID付きで示してください。
```

## Excelが開けない

```text
作成したExcelをClaudeの実行環境で再度開き、全シートを読み取れるか確認してください。破損している場合は同じ内容で新規ファイルとして再生成してください。
```

## PDFが文字化けする

- 日本語対応フォントを使用させる
- 生成後にページ画像を確認させる
- PDFが難しい場合はDOCXを先に作り、そこからPDF化する

## ArtifactとExcelの数字が違う

Artifact内のサンプル値や古い分析結果が残っている可能性があります。

```text
Artifact内のデータをすべて破棄し、検証済みExcelの正規化データと支店別集計だけを基準に再構築してください。全支店と各支店のKPIをExcelと照合してください。
```

## コネクタが表示されない

- Claude Desktopを更新する
- SettingsのConnectorsまたはExtensionsを確認する
- Team／Enterpriseでは管理者が有効化しているか確認する
- 対象プランとOSで利用可能か確認する
- 基本編はファイルアップロード方式で続行する

## ローカルフォルダへアクセスできない

- Desktop Extensionの許可フォルダを確認する
- フォルダを広く許可しすぎない
- ファイルアップロード方式へ切り替える
- Coworkでフォルダを選択できる場合は専用のデモフォルダだけを選ぶ

## 利用上限へ達した

- 長い会話を分ける
- 調査、作成、監査を別チャットにする
- 途中成果物をダウンロードしておく
- Artifactの細かな装飾修正を後回しにする

## デモ中のネット障害

事前に次を用意します。

- 完成済みExcelのスクリーンショット
- 完成済みPDF
- Artifact操作の録画または画像
- 調査結果の例
- コネクタ部分を省略した60分版の進行

## 絶対に避けること

- 本番の顧客データをデモへ使う
- メールを確認なしで送信する
- Driveの既存ファイルを確認なしで上書きする
- ホームフォルダ全体をローカル拡張へ許可する
- AIが「検証済み」と言っただけで正しいと扱う
