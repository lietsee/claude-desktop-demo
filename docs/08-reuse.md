# フェーズ7：成功した仕事を再利用する

## 目的

一度成功した依頼を、次回も同じ品質で始められるようにします。

Claude Desktopでは、まず次の2段階で再利用するのが簡単です。

1. Project instructionsへ恒常的なルールを置く
2. 定型業務の開始プロンプトを保存する

Plugin／Skillは、複数人や複数業務へ展開する段階で検討します。

## Project instructionsに置くもの

毎回変わらない仕事の原則を置きます。

例：

- 元データを変更しない
- 推測で値を補完しない
- エラー行は根拠付きで分離する
- 作業前に調査結果と処理計画を示す
- 件数と金額の整合を検証する
- 完了報告に未解決事項を含める

## Project instructionsに置かないもの

- 今月だけのファイル名
- 今回だけの支店名
- 一時的な金額
- 秘密情報やパスワード
- 長大な業務要件全文

詳細要件はProject knowledgeの文書として管理します。

## 使用プロンプト

`demo-prompts.md` の「9. Project instructions作成」を使用します。

Claudeに今回の会話から、恒常ルールだけを抽出させます。生成された文章を人間が確認してProject instructionsへ貼ります。

## 定型プロンプト

`demo-prompts.md` の「10. 翌月処理テンプレート」を生成させます。

テンプレートには次を含めます。

- 今月の入力ファイルを確認する
- 要件書との差分を調査する
- いきなり成果物を作らない
- 調査結果と計画を提示する
- 承認後にExcel、PDF、Artifactを作る
- 独立検証を行う

## 再利用テスト

新しいチャットを開き、Project instructionsが有効な状態で次を入力します。

```text
今月分の売上CSVを処理したいです。まず何を確認し、どの順番で進めるか示してください。まだ成果物は作らないでください。
```

Claudeが自動的に元データ保護、調査、計画、検証を含む進め方を提示すれば成功です。

## Plugin／Skillへ進む目安

次の条件が揃ったら検討します。

- 同じ処理を何度も行う
- 複数のProjectsで使いたい
- 複数人へ同じ手順を配布したい
- コネクタや専用ツールもまとめて配布したい
- 手順名を `/...` から呼び出したい

Claude DesktopのChatでは、インストール済みPluginに含まれるSkillを利用できます。ただし、Pluginの作成・配布・更新には運用設計が必要です。初心者向け実演では、Project instructionsと定型プロンプトを先に理解させる方が実用的です。

## 完了条件

- Project instructionsが短く、恒常ルールに限定されている
- 翌月用テンプレートが作成されている
- 新しいチャットでも望ましい進め方が再現される
