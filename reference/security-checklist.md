# Claude Desktopデモ安全チェックリスト

## データ

- [ ] 教材のダミーCSVだけを使用する
- [ ] 顧客名、住所、メール、電話番号を含めない
- [ ] 本番の会計・人事・医療情報を使用しない
- [ ] 生成ファイルを公開してよい内容か確認する

## Projectとファイル

- [ ] Project knowledgeへ必要なファイルだけを追加する
- [ ] 古い成果物を元資料と混在させない
- [ ] `input/` を変更しない
- [ ] ローカルアクセスはリポジトリフォルダだけに限定する

## コネクタ

- [ ] デモに必要なコネクタだけを有効にする
- [ ] 接続先アカウントと権限を確認する
- [ ] 書き込み前に保存先・宛先・内容を復唱させる
- [ ] 同名ファイルを確認なしで上書きしない
- [ ] メールは送信せず下書きまでにする
- [ ] デモ終了後、不要な接続を解除する

## Desktop Extension

- [ ] 公式または信頼できる提供元か確認する
- [ ] 要求する権限を確認する
- [ ] ホームフォルダ全体を許可しない
- [ ] パスワード、SSH鍵、環境変数、ブラウザプロファイルを含む場所を許可しない
- [ ] 組織の許可リスト方針に従う

## Cowork／コンピュータ操作

- [ ] 画面上に秘密情報を表示しない
- [ ] 本番サービスへログインした状態で実演しない
- [ ] 削除、送信、公開、購入、承認を自動実行させない
- [ ] 専用コネクタがある操作はコネクタを優先する
- [ ] 操作対象アプリとファイルを明示する

## 検証

- [ ] Claudeの完了報告だけを信用しない
- [ ] 元CSVから数値を再計算させる
- [ ] 新しいチャットで監査する
- [ ] Excel、PDF、Artifact間の数値を照合する
- [ ] 重大な外部共有前に人間が最終確認する
