# フェーズ4：インタラクティブArtifactを作る

## 目的

同じ分析結果を、表計算ファイルではなく、操作できるダッシュボードとして見せます。

## Artifactとは

Claudeが作成する、会話とは別枠で表示・編集・再利用できる独立した成果物です。HTML、React、文書、図などを作成できます。

この教材では、支店別の売上を確認するインタラクティブダッシュボードを作ります。

## 使用プロンプト

`demo-prompts.md` の「6. Artifactダッシュボード」を使用します。

## 必須機能

- 全体の純売上額
- 支店別の純売上額
- 売上件数と返金件数
- 来店人数
- 支店フィルター
- 金額順の並び替え
- 返金行の識別
- エラー件数と注意表示

## 重要な指示

Artifactへ元CSVを再解釈させるのではなく、前フェーズで検証済みの正規化データを使わせます。

分析処理と表示処理を同時に変更すると、ExcelとArtifactで数値がずれる原因になります。

## 実演で操作すること

1. 全支店表示の合計を確認する
2. 東京支店だけに絞る
3. 純売上額順へ並べ替える
4. 返金行だけを確認する
5. 画面幅を狭くして表示を確認する
6. Excelの支店別集計と数字を照合する

## 良いArtifact

- 操作しても合計値が正しく再計算される
- 選択中のフィルターが分かる
- 円表記が読みやすい
- エラーを正常データへ混ぜていない
- 元データの個人情報や秘密情報を埋め込んでいない

## よくある問題

### サンプル値が混ざる

```text
サンプル値や仮の値をすべて削除し、今回の検証済みデータだけでArtifactを構成してください。画面上の全数値をExcelの支店別集計と照合してください。
```

### フィルター後の合計が変わらない

```text
表示中のレコードを基準にKPIを再計算するよう修正してください。全支店、各支店、返金のみの各状態で期待値を確認してください。
```

### 見栄えだけ良く数値が不明確

```text
装飾を増やすより、純売上額、件数、来店人数、返金、エラーの関係が一目で分かる情報設計へ修正してください。
```

## Artifactとファイル成果物の使い分け

| 成果物 | 向く用途 |
|---|---|
| Excel | 詳細確認、再集計、社内保存 |
| PDF | 上司・顧客への固定形式の報告 |
| Artifact | 対話的な探索、比較、説明 |

## 完了条件

- フィルターと並び替えが動く
- 主要数値がExcelと一致する
- 返金とエラーを誤解しない表示になっている
