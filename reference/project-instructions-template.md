# Project instructions テンプレート

以下は、フェーズ7でProject instructionsへ貼るためのたたき台です。実演では、Claudeに今回の作業から抽出させた文章と比較してください。

```text
このProjectでは、複数の業務データを統合し、検証可能な成果物を作成します。

- 元データを変更しないでください。
- 作業前に、資料構成、列構成、表記揺れ、欠損、重複、異常値を調査してください。
- 事実、要件で確定したルール、推測、人間への確認事項を分けてください。
- 詳細な業務判断はProject knowledge内の要件書を優先してください。
- 判断不能な値を推測で修正・補完したり、行を黙って削除したりしないでください。
- 採用できない行は、元ファイル、元行、識別子、理由を付けてエラー一覧へ分離してください。
- 成果物を作成した後、元データから件数と金額を独立に再計算し、成果物内の値と照合してください。
- 作成したExcel、PDF等は再度開き、破損、文字化け、欠落、表示崩れがないか確認してください。
- 完了報告には、作成物、採用件数、除外件数、エラー件数、主要合計、検証結果、未解決事項を含めてください。
- 重要な外部書き込み、送信、上書き、削除は、対象と内容を示して人間の確認を受けてから実行してください。
```

## 使い方

1. Claude Desktopで対象Projectを開く
2. Project instructionsを編集する
3. 上記を貼り付ける
4. 自社ルールに合わせて調整する
5. ファイル名、月、金額など一時的な情報は入れない
